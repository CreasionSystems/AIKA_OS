# Architecture Decision Records

設計上の決定を1件1ファイルで残す。各 ADR は「背景 / 選択肢 / 決定 / 結果・制約 / 実装対象外」を持つ。

採用済み ADR は実装契約として扱う。ADR と矛盾する変更を行う場合は、既存 ADR を supersede する新しい ADR を先に起こす。
